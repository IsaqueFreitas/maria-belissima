# Paulo Nunes Hair

A modern and sophisticated institutional landing page developed for **Paulo Nunes Hair**, a professional specializing in the care and enhancement of curly hair.

The project aims to showcase the professional's work, services, and transformations while providing a premium visual experience and making it easy for clients to get in touch and schedule appointments.

## Technologies

* React
* TypeScript
* Vite
* Tailwind CSS
* Framer Motion
* Lucide React
* ESLint
* Prettier

## Features

* Fully responsive landing page
* Section-based navigation
* Services showcase
* About section
* Transformation gallery
* Smooth animations and transitions
* WhatsApp integration for appointment scheduling
* Instagram integration
* Responsive mobile menu
* Image lightbox

## Project Structure
